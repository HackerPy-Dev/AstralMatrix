## 📖 О проекте

Веб-приложение для самопознания, объединяющее две мощные эзотерические системы: **Матрицу Судьбы** и **Натальную Карту**. 

Инструмент позволяет ввести данные рождения и получить персонализированный анализ личности, основанный на нумерологических расчетах и астрологических положениях звёзд.

## ✨ Возможности

### 🔢 Матрица Судьбы
*Нумерологическая карта вашего воплощения*
*   Расчет ключевых чисел судьбы.
*   Анализ энергетических потоков личности.
*   Понимание кармических задач.

### ⭐ Натальная Карта
*Астрологический портрет личности*
*   Построение карты на основе даты, времени и места рождения.
*   Учет приблизительного времени рождения (специальные presets).
*   Интерпретация положения планет и знаков зодиака.

## 🚀 Как запустить

Проект реализован как статическое веб-приложение. Для запуска не требуется сложная настройка сервера.

1.  **Скачайте репозиторий:**
    ```bash
    git clone https://github.com/your-username/your-repo.git
    ```
2.  **Перейдите в папку проекта:**
    ```bash
    cd your-repo
    ```
3.  **Откройте файл `index.html`:**
    Просто откройте файл в любом современном браузере (Chrome, Firefox, Safari).

    *Или используйте локальный сервер (например, Live Server в VS Code).*

## 📝 Как использовать

### Для Матрицы Судьбы:
1.  Введите **дату рождения** (обязательно).
2.  Укажите **имя** (необязательно, для персонализации).
3.  Нажмите кнопку **«Рассчитать матрицу»**.

### Для Натальной Карты:
1.  Введите **дату рождения**.
2.  Выберите **приблизительное время рождения** из списка:
    *   Не знаю (~полдень)
    *   Утро (~6:00 | ~9:00)
    *   День (~12:00 | ~15:00)
    *   Вечер (~18:00 | ~21:00)
    *   Ночь (~0:00 | ~3:00)
3.  Введите **город рождения**.
4.  Нажмите кнопку **«Построить карту»**.
